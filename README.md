# Avatar Menu: a simpler way to navigate Telegram

A concept for replacing the bottom navigation bar with a round avatar button that opens a full-width menu.

**[Try the live demo](https://github.com/bogdandepakarev/telegram-avatar-nav.git)**

## The problem

The bottom navigation bar takes up space on every screen and holds buttons that people tap only now and then. The chat list, which is what people actually use, gets less room.

## The idea

Remove the bottom bar. Put a round avatar button in the top-right corner instead. Tapping it opens a panel that grows smoothly out of the avatar and gives quick access to:

- Profile
- Contacts
- Saved Messages
- Settings

## How it feels

- The panel expands from the avatar, so it is clear where it came from.
- The chats behind it are blurred, which keeps attention on the menu.
- Close it by tapping outside, swiping up, pressing Esc, or tapping the avatar again.
- Works in light and dark themes and respects reduced-motion settings.

## Why it's better

- More space for chats.
- A cleaner, calmer screen.
- Every section is still one tap away.

## Run it

No installation needed. Open `index.html` in a browser. For a phone-like view on a computer, open DevTools (F12) and turn on device mode.

## What's inside

A single file built with plain HTML, CSS and JavaScript, with no dependencies.
